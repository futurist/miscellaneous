Introducing VS Code Insiders Podcast

A new way to stay connected with Visual Studio Code

What is the VS Code Insiders Podcast?

The VS Code Insiders Podcast is a new initiative from the Visual Studio Code team to bring you closer to the development process and the people behind your favorite code editor.

  • Behind-the-scenes insights into VS Code development
  • Interviews with team members and community contributors
  • Updates on new features and roadmap
  • Tips and tricks from the experts

Why a Podcast?

The team wanted to create a more personal and engaging way to connect with the VS Code community.

"We realized that there's so much happening behind the scenes that our users would love to know about, and a podcast is the perfect medium to share these stories."

The podcast format allows for:

  • In-depth discussions about technical decisions
  • Casual conversations with the development team
  • Community feedback and Q&A sessions
  • Accessibility for users on-the-go

Episode Topics

Each episode will cover different aspects of VS Code:

  1. Feature Deep Dives: Detailed explorations of new and existing features
  2. Extension Ecosystem: Highlighting popular extensions and their creators
  3. Performance & Architecture: How VS Code stays fast and efficient
  4. Community Spotlights: Featuring contributions from the open-source community
  5. Future Vision: What's coming next for VS Code

How to Listen

The VS Code Insiders Podcast is available on all major podcast platforms:

  • Spotify
  • Apple Podcasts
  • Google Podcasts
  • YouTube
  • RSS Feed for your favorite podcast app

New episodes will be released bi-weekly, with special episodes for major releases and events.
